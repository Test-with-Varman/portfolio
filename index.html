Projects

End-to-end automation and validation across a real e-commerce flow.

Project

E-Commerce Test Automation Framework (SauceDemo / SwagLabs)

Problem

E-commerce workflows involve dynamic product states, authentication variations, cart validation, and checkout verification — all areas where small issues create large user-facing problems.

Approach

I architected a modular Page Object Model (POM) framework in Java using Selenium WebDriver, enforcing OOP encapsulation and reusable structure. I integrated Apache POI to read large Excel datasets, used TestNG DataProvider for comprehensive positive and negative login matrices, and built utilities for dynamic screenshot handling, centralized properties configuration, and testng.xml suite control.

Result

The framework improved reliability and coverage for cart state management, product sorting, and checkout validation while making test execution more scalable, maintainable, and efficient.
